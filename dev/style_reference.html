Symmetrical CSS Color Tokens

Every surface, text, border, accent, and status token has a dedicated role and state pair.

1. Surfaces (--surface-*)

--surface-canvas Root viewport backdrop
--surface-base Default cards and panels
--surface-raised Modals, popovers, active tabs
--surface-sunken Recessed wells and tracks

2. Text & Foreground (--text-*)

Primary text — headings and core body copy --text-primary
Secondary text — supporting labels and descriptions --text-secondary
Muted text — metadata, captions, placeholders --text-muted
Disabled text — inactive controls or unavailable items --text-disabled
Text on solid fill --text-on-solid

3. Borders & Focus (--border-*)

--border-subtle Soft dividers & quiet edges
--border-default Standard outlines & fields
--border-strong High-contrast boundaries
--border-focus

4. Accent — Solid vs. Subtle (--accent-*)

Solid pair: --accent-solid, --accent-solid-hover, --accent-solid-active, --accent-on-solid
Subtle pair: --accent-subtle, --accent-subtle-hover, --accent-subtle-active, --accent-text, --accent-border

5. Semantic Status (--<state>-*)
